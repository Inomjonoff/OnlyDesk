# ADR-050: AI Session Intelligence and Fact-Based Reporting

## Status

Accepted

## Context

Support sessions generate valuable diagnostic history and actions that need to be summarized accurately for post-session audit and ticketing integration without hallucination.

## Decision

1. Implement `SessionFactStore` to record verified facts (e.g. telemetry anomalies, verified action results) during the session lifecycle.
2. Reports are generated by `SessionReportGenerator` using evidence-grounded facts.
3. Every recommendation must cite corresponding evidence collected during the session.
4. If critical issues occurred without verified fixes, the session resolution is marked as `UNRESOLVED` or `PARTIALLY_RESOLVED`.

## Consequences

Generates verifiable, high-trust session audit summaries suitable for enterprise compliance.
