# ADR-061: Public Beta Architecture & Productization

## Status
Accepted

## Context
NexusDesk AI must transition from an infrastructure demonstration to an intuitive, self-service public beta product usable by non-developers.

## Decision
1. Implement a complete user lifecycle: Landing → Onboarding Checklist → Desktop Download → Device Pairing → Connection HUD → Session History & AI Reports.
2. Establish transparent, fact-based security and privacy documentation rather than ambiguous marketing claims.
3. Decouple public status pages and client compatibility verification from internal core APIs.

## Consequences
- Frictionless end-user onboarding while preserving strict zero-trust security boundaries.
- Transparent communication regarding beta capabilities and system health.
