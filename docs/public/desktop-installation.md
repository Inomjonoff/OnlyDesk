# Desktop Installation & Setup — Windows x64

## System Requirements
- Windows 10 (64-bit) or Windows 11
- 2 GB RAM minimum (4 GB recommended)
- Stable internet connection (outbound UDP enabled)

---

## Installation Steps
1. Download `NexusDesk-v1.0.0-beta.1-setup.exe`.
2. Double-click the installer.
3. If Windows SmartScreen displays an "Unknown Publisher" prompt (common for beta software), click **More Info → Run Anyway**.
4. Sign in with your registered account.
5. Your device will automatically generate a cryptographically bound Ed25519 keypair and display your Device ID.
