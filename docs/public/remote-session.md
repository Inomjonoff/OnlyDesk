# Remote Session User Guide

## Core Capabilities

- **Ultra-Low Latency Video**: Powered by native DXGI desktop duplication and H.264 / VP8 WebRTC pipelines.
- **Bi-directional Remote Input**: Smooth mouse movement and full keyboard mapping with Windows SendInput.
- **Encrypted File Transfer**: Peer-to-peer data channel transfer with SHA-256 chunk validation.
- **In-Session Chat**: Real-time messaging with your support engineer.
- **Session Screen Recording**: Optional, consent-gated recording stored privately in encrypted object storage.
- **AI Diagnostic Copilot**: Interactive AI assistance for troubleshooting system performance and application errors.
