# Vulnerability Disclosure & Security Response Policy

## 1. Reporting a Vulnerability
We welcome security researchers and community members to report potential vulnerabilities responsibly.

- **Security Contact**: `security@nexusdesk.uz`
- **PGP Encryption**: Available upon request.
- **Scope**: API endpoints, WebRTC signaling, native client input injection, secret redaction, and AI sandboxing.

---

## 2. Response Timelines & Severity Matrix
- **Critical (SEV-1)**: Triage within 4 hours; mitigation/patch within 24 hours.
- **High (SEV-2)**: Triage within 12 hours; patch within 72 hours.
- **Medium / Low (SEV-3 / 4)**: Triage within 48 hours; release in next sprint cycle.

We ask for at least 30 days of coordinated disclosure prior to public release.
